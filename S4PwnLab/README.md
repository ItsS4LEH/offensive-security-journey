# S4PwnLab

**بالعربي:**  
S4PwnLab هو بيئة معامل عملية لتعلم وممارسة تقنيات الأمن السيبراني، من مختبر الاختراق المبتدئ إلى عمليات الفريق الأحمر المتقدمة.

**بالإنجليزية:**  
S4PwnLab is a hands-on lab environment for learning and practicing cybersecurity techniques, from beginner pentesting labs to advanced Red Team operations.
